# Portfólio Gabriel Pinheiro

Site estático: `index.html` (portfólio) e `cases/` (13 páginas de case).

## Publicar na Vercel

No Terminal, dentro desta pasta:

    npx vercel --prod

Na primeira vez, a Vercel pede login (abre o navegador) e algumas perguntas.
Pode aceitar os padrões (Enter). Nas próximas atualizações, basta rodar o mesmo comando.
